Quick start

Set up your workspace.

01 / Update Termux

Refresh package indexes before installing packages.

pkg update && pkg upgrade

02 / Core developer tools

Install Git, Python and Node.js.

pkg install git python nodejs

03 / Your workspace

Create a project folder in Termux home.

mkdir -p ~/projects && cd ~/projects
Safety first

Understand before you run.

This is a command reference, not a remote shell. The website never runs commands on your device, never asks for your passwords or tokens, and does not need root access. Read every command before pasting it. Only connect to systems you own or are authorized to administer.
